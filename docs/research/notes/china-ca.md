目标场景：**中国大陆的个人开发者，无公司/无营业执照**。

## 2. 沃通 WoSign —— **【官方】**

### 2.1 产品与价格（`https://www.wosign.com/Products/code_signing.htm`）

| 产品 | 价格（官网标注） |
|---|---|
| EV 代码签名证书 Pro | **￥6888 / 年** |
| EV 代码签名证书 Pre | **￥5880 / 年** |
| EV 代码签名证书 | **￥4288 / 年** |
| 标准代码签名证书 Pro（OV） | **￥4888 / 年** |

同页功能对比行明确：EV 档写 `SmartScreen即时信誉`；而普通档（OV）该列写 `累计下载获得`——**这是沃通自家产品页的表述**，与 Microsoft 官方文档（见 `smartscreen-ov-ev.md`）不一致，属过时营销口径，报告中须标注。

### 2.2 多年期价格（`https://www.wosign.com/Products/OV_CodeSigning_Pro.htm`）

| 年限 | 价格 |
|---|---|
| 一年 | **￥4888 元** |
| 二年 | **￥8588 元** |
| 三年 | **￥12688 元** |

计算：三年 ￥12688 ÷ 3 = ￥4229.3/年，相对一年 ￥4888 **约省 13%**；该页未标注涨价或续费条款。

### 2.3 个人资格：**否**（关键原文）

同一页（`OV_CodeSigning_Pro.htm`）原文：

> `单位为代码签名证书Pro，颁发根证书为：DigiCert Trusted G4 Code Signing RSA4096 SHA384 2021 CA，证书主题中"O"字段(Organization)会显示申请单位的中文名称。`

> `(1) 单位代码签名证书Pro 又分英文版和中文版，英文版的软件发行商名称为公司英文名称，如果用户有英文名称证明材料，请提交英文证明材料；而中文版的软件发行商名称为公司中文名称,也就是营业执照上的中文名称。用户在在线申请 单位代码签名证书Pro 时，只要在机构名称(Organization)中填写中文名称即可申请中文版。`

> `(2) 如果要申请英文版，但又不能提供英文名称证明材料，我们认可中文名称营业执照作为证明文件，申请时填写的公司英文名称必须是中文名称的通用英文单词翻译，商号必须是拼音或相近英文发音。`

**要点**：证书 O 字段必然是「申请单位的中文名称」，且证明材料认可的是**营业执照**。全站产品列表（`https://www.wosign.com/Products/`）中代码签名相关条目为：`代码签名证书 / EV代码签名证书 Pro / 标准代码签名证书 Pro / EV代码签名证书 / 标准代码签名证书 / WHQL徽标认证服务`——**没有任何面向自然人的个人代码签名档位**。

另注：沃通产品页有免责条款原文 `沃通有权核实用户购买代码签名证书的用途，如发现非本单位使用或有签名恶意软件的意图，有权拒绝颁发。`——「非本单位使用」即排除个人代买。

### 2.4 介质与合规（同页原文）

> `国际标准要求，OV代码签名证书自2023年6月1日起，与EV代码签名证书一样，必须采用硬件安全设备（HSM、USBKey等）存储证书，证书从生成到签发使用，私钥始终被存储在硬件令牌或硬件安全模块中，不支持导出，有效降低证书私钥被泄露的风险。`

→ OV 与 EV 均需硬件介质，**硬件是成本的一部分**（沃通未在页面单列硬件价，标价是否含硬件**未找到**）。

## 7. 三问逐答（针对中国国内 CA）

### 7.1 个人（非公司实体）能否申请？

| CA | 结论 | 依据 |
|---|---|---|
| 沃通 | **否** | O 字段为营业执照中文名称；产品线无个人档；条款排除「非本单位使用」 |
| 上海 CA | **否**（官方未给个人路径） | 证书显示「组织名称」；文案写「显示公司名字」 |
| 天威诚信 | **未找到** | 官方页无个人/企业资格表述 |
| CFCA | 不适用（无该产品） | 官网未列 |

### 7.2 中国大陆居民能否申请？

- **地理上无障碍**：四家均为中国大陆注册机构，无需跨境购买，硬件（安全令牌）国内寄送，不存在跨境运费或海关问题（对比 Certum 的 China €35.00 运费与可能的海关税）。
- **但主体门槛横在个人面前**：沃通与上海 CA 的证书字段要求组织名称/营业执照，**大陆个人即使地理可达也过不了主体资格这一关**。
- 天威诚信是否给个人签，**未找到**。

### 7.3 隐藏成本？

| 项目 | 情况 |
|---|---|
| 硬件令牌 | 沃通：OV 与 EV 均强制硬件存储（官方原文），**标价是否含硬件未找到**；上海 CA：存储介质为「安全令牌介质」 |
| 邮寄费 | 各页**均未列**邮寄费，**未找到** |
| 加急费 | **未找到** |
| 续费涨价 | **未找到**（沃通只列 1/2/3 年价，无续费条款） |
| 多年期折扣 | 沃通 OV Pro：三年 ￥12688（约 ￥4229/年）比一年 ￥4888 省约 13% |

## 8. 与海外方案的对比要点（供最终报告使用）

- **对中国大陆个人而言，国内 CA 路线实际不可行**：不是买不到，而是**主体资格**卡死——国内 CA 的代码签名产品设计上就是给企业/单位用的，证书里要印组织名称。
- 相比之下，**Certum Open Source 档是唯一明确「只发给自然人」的选项**（详见 `certum.md`），且能把含加密卡的 set 寄到中国大陆（运费 China €35.00）。
- **SSL.com 的 IV 档**（$129/yr，`Business entity required: No`）是另一个对个人开放的选择（详见 `sslcom.md`）。
- **Sectigo 官方知识库明确支持个人申请 OV**（视频面签 + 政府签发带照片身份证件，详见 `big-three.md`）。
