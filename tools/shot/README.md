# 应用窗口截图

给 README 的应用截图用的取图工具。抓的是**窗口自己渲染的画面**，不受窗口遮挡、DPI 缩放影响。

## 用法

在仓库根目录执行：

```powershell
# 看当前有哪些候选窗口（确认逻辑尺寸是 1280x720）
.\tools\shot\capture.ps1 -List

# 截一张，写到 docs/screenshots
.\tools\shot\capture.ps1 -Out docs\screenshots\appearance.png
```

流程就是：**把窗口摆好 → 翻到目标页面 → 跑一条命令**。

## 尺寸要求

README 的截图统一是 **1280x720 逻辑尺寸**。手上有 150% 缩放时，对应的物理尺寸是
1920x1080，所以 `-List` 里看到「物理 1920x1080 / 逻辑 1280x720」才是对的。

尺寸不符时脚本只**警告**，不会擅自改窗口——改窗口会把你当前的浏览状态弄丢。
自己拖一下窗口角到合适的尺寸再截即可。

## 为什么不用 CopyFromScreen

本机 DPI 是 150%，`GetWindowRect` 返回的是**物理坐标**，而 `CopyFromScreen` 按屏幕物理
像素取景。两者语义不一致，一旦再乘一次缩放系数就会把窗口外的桌面一起截进来。

`PrintWindow` 是让窗口把自己画到内存 DC，坐标系由系统换算，天然避开这个问题。

## 打码

截图入库前必须处理敏感内容（**影片封面**、**用户名 / 头像 / UID**），做法沿用现有几张
图的风格：

- 封面区域整体模糊
- 用户昵称、头像、UID 模糊
- 界面文字、设置项、按钮保持清晰

`docs/screenshots/` 下的图会被 README 直接引用，提交前自己再确认一遍没有漏掉的敏感信息。
